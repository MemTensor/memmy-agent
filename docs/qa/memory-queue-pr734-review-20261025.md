## 审核意见与修复

1. [连续补位的 smoke 断言](https://github.com/MemTensor/memmy-agent/pull/734#discussion_r4370332832)：按有限轮次汇总执行结果，不再要求向量固定在第二轮执行；覆盖预算 1/20、摘要及向量各成功一次、真实向量落库、读取、召回和空闲重复调用无副作用。
2. [无关释放导致扫描反复归零](https://github.com/MemTensor/memmy-agent/pull/734#discussion_r4370340655)：释放通知携带具体资源，等待集合按受阻资源保存候选，保留深扫描进度；相关释放后按原 FIFO 位置重试，配置/分类/到期变化仍正确失效。覆盖 20,000 条受阻记录、持续干扰、Aging 开关、旧任务恢复及并发边界。
3. [有效分类仍反复全量扫描](https://github.com/MemTensor/memmy-agent/pull/734#discussion_r4370348364)：以事件更新分类，缺失/旧分类进入部分索引；异步补位每片共享最多 64 条维护预算，终态历史不进入活跃维护。分类版本升为 3，升级补齐可恢复；缩小普通属性更新触发范围。保留同一未完成任务的首次报告/主动重试待遇，独立新任务不继承；去重不改变 FIFO 身份。

默认参数保持全局 4、后台最多 3、实时预留 1；WRR 4/3/2/2/1。
