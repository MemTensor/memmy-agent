## 已因果复现并修复的通用缺陷

1. **初始化通知乱序**：真实隔离 Chromium 中，只延迟 `Page.getFrameTree` 回复 150ms，`Runtime.enable` 的上下文事件就可能先到。普通页面与沙箱跨域子页面均可复现原代码快照挂起；页面脚本和实际事件未被篡改。修复为同 CDP session 的结构回复发出后再启用 Runtime；未知/被排除 frame 仍按原策略拒绝。
2. **整次操作没有截止时间**：等待默认执行上下文时可能根本没有在途 CDP 命令，单命令超时和 8 秒 locator 超时均不能退出。新增每轮 30 秒期限，取消待决命令、断开执行传输并唤醒调用；不会自动重放输入。
3. **取消与清理互相等待**：先撤销当前操作和断开本地连接，再最多用 2 秒清理原 lease；旧清理保留原 lease ID，不能解绑新任务的 lease。缺上下文后，同标签页可重新建立快照执行器。
4. **展示预览阻塞结果**：额外预览最多等待 3 秒，跟随任务取消；完成的文字快照/动作结果可以返回，迟到的预览不再发布。
5. **停止期间迟到输入**：插件在 `chrome.tabs.get` 等待后重新检查取消及保护状态。两个回归在修复前分别仍创建 lease、仍发送 `Input.insertText`，修复后均在派发前退出。额外覆盖用户活动检查期间的停止/并发 Start，以及最后一次标签页读取期间的同源导航/lease 到期：旧 Start 不覆盖新任务，旧动作不进入新文档。插件版本升为 `1.0.7`，沿用现有自动更新机制。

增加 `[browser-executor]` 开始/完成/失败阶段诊断，记录操作类型、随机关联 ID、耗时、阶段和错误码，不记录 URL、网页、账号、输入内容或文件路径。

内置浏览器、Chrome/Edge 共用的 Agent 执行层均包含修复；插件取消重查适用于 Chrome/Edge。没有新增 GUI、网站规则、模型提示规则、数据结构迁移或手动安装流程。
