# 浏览器与 History 整合测试：1.2.4-rc.3

## 发布范围与基线

本轮以远端 `release/v1.2.3` 的 `c093cbcb2b876901c967e7abf354097a45f8c298` 为基线，再叠加本次浏览器执行、History 和 Mac PiP 权限改动。该提交是整合分支的真实祖先；打包前必须验证这一点，并在交付记录中固定最终源码 SHA。

基线包含同事及用户已合入 1.2.3 的修复：启动就绪顺序与 MCP 桥接（#638）、Windows Excel 连接（#632）、内置浏览器新窗口链接与文件总览（#630）、Anthropic 请求头（#633）、模型输入和输出上限（#629），以及 History、Memory 和打包检查修订。

远端另一条 `v1.2.4` 分支的社交登录、插件生命周期及运行时打包改动由其原负责人继续处理，本轮不纳入。当前测试号为 1.2.4-rc.3；是否赶入 1.2.3，由用户验收后决定，并按确定版本重新构建。

## 界面与交互范围

- History 的微信区域下新增可展开的「网页历史记录增强」，共用 Computer Use 的 Chrome / Edge 插件安装入口和连接状态。这不是新开关。
- CDP 审批新增此前已确认的「始终允许此网站」，可在网站权限设置中撤销。
- 沿用已有插件随安装包替换文件、空闲时检测版本并自动重载和重连的机制；本轮不新增 Memmy 升级弹窗、横幅或手动升级步骤。
- 内置浏览器、Chrome、Edge 的执行增强使用同一套通用执行能力；内置浏览器不依赖外部插件。
- Chrome / Edge 网页语义操作进入现有统一 History，没有单独示范模式。沿用 History 的记录、暂停和排除设置。
- 浏览器系统调试条由浏览器控制；被动 History 记录不保持调试连接。

## 升级兼容性约束

- 保留 appId、安装目录、用户数据目录、账号与配置、聊天、History 和 Memory 数据位置。
- 保留内置浏览器 `persist:memmy-browser` 登录分区，以及现有网站权限文件和插件身份。
- Memory 仍为 2.1.6、schema 9、protocol 1；使用包含本轮完整基线源码的新 buildId。不能复用旧 rc.2 的 staged runtime，也不能回退到其它分支的旧 Memory。
- 安装、迁移和 runtime ownership 沿用 release 实现。同版本不同 buildId 的 Memory 更新仍须保留数据并遵守版本/schema 防回退。
- 保留 release 的 Agent-ready、Local API 与 MCP 启动顺序。不能用旧 rc.2 的整份启动文件覆盖。
- Mac 和 Windows 从同一冻结源码分别构建，使用独立可变输出和依赖目录。

## 用户优先回归

| 场景 | 操作与通过标准 |
| --- | --- |
| 1.2.3 覆盖升级 | 覆盖安装后，确认版本、账号、旧聊天、History、Memory、设置和授权保留；能正常启动和继续已有任务。已用 rc.2 的测试机也检查覆盖到 rc.3。 |
| 已有浏览器插件 | 保持原插件已安装，正常升级 Memmy，观察插件自动更新与重连后可用；记录任何额外的浏览器系统提示或卡住位置。Memmy 不应新增升级引导弹窗或横幅。 |
| 启动与旧任务 | Windows 普通启动与重启后，主界面可连接并执行任务；Mac 启动、PiP 和屏幕录制权限流程继续正常。 |
| Excel 与文件总览 | 重试 Windows Excel 首次连接；检查内置浏览器打开新窗口链接、只有浏览器标签时查看文件总览。 |
| 三种浏览器 | 分别测试已有登录、输入、下拉、勾选、弹窗、动态加载与滚动后的操作，观察实际控件状态及任务结果。 |
| 多任务与接管 | 两个任务使用不同标签页，不串页；停止任务或用户接管后停止旧动作，恢复符合现有流程。 |
| 网站与文件权限 | 检查访问阻止、上传、下载、凭据保护；「始终允许此网站」沿用相同协议/域名/端口的 CDP 授权，撤销后再次审批。 |
| History 入口 | 两处入口共用安装及连接状态，首次未开启 History 也能安装；展开/收起不改变记录开关。 |
| 手动网页记录 | 开启 History、无 Agent 任务时，手动输入、勾选、选择和跳转；动作与状态变化进入同一 History，暂停和排除规则有效，密码与验证码不进入内容。 |
| 原业务样本 | 重跑 Windows 开票准备及查询勾选发票任务，记录完成情况、耗时、重复点击和审批次数。 |

网页记录区分操作尝试、已观察变化和新页上下文；快速整页卸载可能来不及送达全部前态，未确认的导航或提交不能记为成功。
