## 授权行为

电脑操控「始终允许任意应用」覆盖应用操控，以及内置浏览器、Chrome/Edge 插件和其他现有浏览器执行路径的网页访问、操作、上传、下载、CDP 读写/事件及已有的内置浏览器历史读取。

网站权限新增独立的「始终允许所有网站」。电脑总开关开启时该设置显示继承，不能在网站页假性关闭。电脑总开关关闭后，继承授权撤回；用户独立开启过的网站总授权保留。两类授权均不批量改写逐网站记录。

全部允许优先于单网站阻止；关闭后原有细分设置恢复。网站摄像头、麦克风、位置等设备权限仍单独管理。History 的录制、暂停和排除规则不受操作总授权改变。

设备权限单独管理不要求用户手动完成任务。任务需要时，Agent 可通过当前网站的设备权限工具配置对应授权，并继续网页操作及结果验证；外部浏览器保留其原生权限界面，由 Agent 用已有 Computer Use 完成。内置浏览器中由 Agent 配置的设备授权只属于当前任务的当前标签和网站，任务期间优先于用户保存的同站设置，但不写入网站权限设置，也不影响用户之后自己浏览；任务结束、标签关闭、标签离开该网站、Agent 重启或满 30 分钟即失效。工具报告站点授权状态并注明仅限本任务（`lasts: "task"`），不把它误报成操作系统权限已授予或设备已成功工作。

网站访问弹窗新增「允许对所有网站操作」，和设置页写入同一项独立网站授权。多入口状态同步；打开总授权时正在等待的同类审批直接继续。两个总开关均关闭时，仍使用按网站、按能力的细分授权。

## 已知任务信息

- 用户已经提供或能从已授权渠道取得的验证码/凭据通过安全填写工具直接输入。只在缺少必要字段时补问，未提供的可选字段直接跳过；工具参数、进度、持久化、恢复记录及模型兼容元数据不保留新增填写值。
- 明确的上传 `paths` 直接使用，仍校验文件、目标标签与任务归属。
- 内置/托管标签支持动作级 `downloadPath`，覆盖保存位置询问，不更改全局目录；只接收已有目录下的新文件，不覆盖已有文件。该目标只属于当前任务的当前标签和本次动作。
- Chrome/Edge 沿用浏览器正常下载，不修改整个浏览器的下载行为或增加插件权限。目的地已知时 Agent 应用已有 Computer Use 填写保存对话框，或移动可靠识别的已完成文件；不能要求用户重述已知位置，也不能凭猜测移动文件。
- 没有任务级位置时，仍遵守「每次下载前询问保存位置」及默认目录设置。

工具与技能说明采用通用任务目标驱动原则：根据工具实际能力、当前状态和结果自主选择及组合执行方式，不固定 API、插件、Computer Use 的使用顺序，不按任务类别预先转人工。需要的信息先从任务相关且已授权的来源取得；遇到真实阻碍后按观测结果处理。接口约束保留输入验证、任务隔离与秘密脱敏，以便模型能力进步后直接采用更好的执行策略。

## 用户验收

Mac 和 Windows 分别执行，记录包版本、最终源码提交与测试结果。

| 场景 | 通过标准 |
| --- | --- |
| 覆盖升级 | 原账号、聊天、History、Memory、设置、授权和浏览器登录态保留，旧任务可继续；启动及首次任务正常。 |
| 旧电脑总授权 | 升级前已经勾选，升级后无需关开一次；内置、Chrome、Edge 不再出现 Memmy 的重复浏览器审批。 |
| 网站独立授权 | 电脑总开关关闭，只开网站总开关；三种浏览器共用效果，其他桌面应用继续按原授权。 |
| 全局覆盖与撤销 | 预置单站阻止，全局开启时能操作；关闭后原规则恢复。单独开启的网站总授权不会因电脑总开关开关一次而丢失。 |
| CDP 与网页历史 | CDP 读取、事件、修改及已有内置浏览历史读取使用总授权；关闭总授权后细分审批正常。 |
| 多入口与待审批 | 设置页、网站弹窗及电脑总开关修改即时同步；总授权开启后待处理审批收敛。重启后状态正确。 |
| 明确验证码与文件 | 不重复收集已知值；文件直接上传到指定页面。密码/验证码不进入工具记录、History 或调试输出。 |
| 明确保存位置 | 内置/托管动作下载进入指定新文件；延迟触发、停止、并发任务不串目标。Chrome/Edge 已知 Save As 由 Agent 完成，最终文件位置可核实。 |
| 设备与隐私 | 操作总授权不自动允许网站摄像头/麦克风等；Agent 为任务开启的内置浏览器设备授权在任务结束、标签关闭或离开该网站后失效，不出现在网站权限设置中，关闭总授权后也不残留；History 暂停/排除与隐私保护继续有效。 |
| 原功能回归 | Windows Excel 首次连接、文件总览/新窗口、Memory 的 Memmy 来源筛选、PiP/录屏许可、网页 History 插件自动更新与重连。 |
| 原业务样本 | 重跑原开票/勾选任务，比较耗时、重复操作、审批次数及实际结果；不把源码通过等同于业务验收。 |

系统授权及 Chrome/Edge 自身调试提示条由对应系统决定。签名、公证、包内校验、源码测试和升级夹具分别记录；真实安装、覆盖升级、原生 Windows 与 GUI 留给用户验收。
