`memmy serve` 默认监听 `http://127.0.0.1:18990`：

| Method | Path |
| --- | --- |
| `GET` | `/health` |
| `GET` | `/v1/models` |
| `POST` | `/v1/chat/completions` |

任何支持 OpenAI Chat Completions 协议的工具或脚本都可以直接复用 Memmy。单独运行不需要下面的宿主设置。把 Agent 嵌进其他应用并由宿主审批工具时，见 [宿主管理的 Agent](/docs/reference/managed-agent)。
