给出研究问题和时间范围后，文献综述插件会检索候选论文、获取可用全文、整理证据，再按大纲撰写综述并生成参考文献。关键词、纳入哪些论文、如何组织章节，都可以在过程中由你确认。它适合梳理一个领域的研究进展，或比较不同研究的方法、结果和局限。

例如，梳理具身智能领域的研究进展时，可以让它比较不同研究对具身智能的定义、学习范式和开放问题的讨论，形成供团队讨论的综述初稿。你也可以加入自己已有的论文，让这些资料进入同一项任务。

## 开始一次综述

1. 文献综述需要登录后使用。在「连接与工具 → 任务插件」中找到「文献综述」，未登录时先登录。
2. 安装后即可直接使用。写明研究问题、年份、希望比较的维度、读者和交付格式。有指定论文时，一并添加文件。

## 过程中确认什么

插件会在关键步骤弹出卡片，请按卡片提示确认：

| 步骤 | 你可以检查或调整 |
| --- | --- |
| 综述需求 | 研究主题、时间范围、写作重点和交付要求 |
| 检索关键词 | 关键词是否覆盖不同叫法，是否偏离研究问题 |
| 入选文献 | 哪些论文参与写作；排除不相关或年份不符的候选 |
| 综述大纲 | 章节是否围绕你要回答的问题组织 |
| 获取全文 | 下载失败时补充自己持有的文件，或继续使用可获取的资料 |

卡片的具体标题和按钮以当前安装版本为准。需要在卡片上完成的确认，要在卡片内操作；聊天中的补充说明不会自动代替这一步。

## 交付后检查什么

打开生成的综述和参考文献，重点核对三件事：

1. **覆盖范围**：入选论文是否回答了原定问题；重要方向是否缺失。
2. **证据与结论**：抽查几处关键结论，确认引用指向相应论文，且没有把摘要或候选列表写成已核实的全文结论。
3. **引文信息**：核对作者、年份和引用位置；遇到缺全文、元数据不完整或下载失败的论文，补充原文或缩小结论范围。

插件会帮助完成检索和写作，但全文能否获取取决于论文的可访问性。综述可作为研究或评审的初稿，正式使用前仍需按原文核对关键结论。

任务消耗 Token 较多，建议使用自行配置且性能较强的模型。目录中是否显示该插件、能否安装，以当前页面和账号资格为准。
