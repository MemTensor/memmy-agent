更新 UI 交互稿

两种方式完全拆开

A 是默认后台静默更新，不要求用户点击；B 是用户主动触发的手动更新，平时可以用，也可以作为自动更新失败后的兜底。

A

A. 后台静默更新

主体验：打开软件后自动检查，发现新版后自动下载，退出后无窗口安装，下次打开就是新版。

A1. 打开 App自动检查
A2. 自动下载后台准备
A3. 已准备退出后安装
A4. 用户退出无界面安装
A5. 下次打开直接新版
A6. 失败兜底不阻塞打开
A1

打开 App，自动检查

用户不需要进设置页，也不需要点击检查按钮。

触发App 启动完成后自动检查
