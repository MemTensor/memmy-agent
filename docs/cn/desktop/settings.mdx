## 选择模型来源

登录 Memmy 账号后，可以使用账号下可用的平台模型，也可以添加自己的 API Key。若不想注册，可在首次欢迎页选择「使用自定义大模型 API Key（无需注册）」。账号与本地 API Key 模式分别管理模型配置。

## 配置自己的 API Key

1. 打开「设置 → 模型配置」，点击右上角的「添加配置」。
2. 按模型服务商提供的信息，填写「协议类型」「API 地址」「API Key」。
3. 在「模型列表」填写「模型 ID」，选择「模型能力」。普通对话选择「通用文本」；同一服务有多个模型时，可点击「添加模型」。
4. 点击「测试」，根据提示修正连接问题。测试通过后点击「保存」，配置会出现在模型库中。

## 让任务使用这个模型

保存配置后，在同页下方的「模型分配 → Agent 任务模型」中，点击显示已选数量的按钮，勾选可用模型并设置默认模型。回到工作台，在「会话模型」中选择本次任务使用的模型。

<summary>其他模型分配分别有什么用？</summary>

- **记忆摘要**：把对话整理成记忆。
- **技能进化**：整理和改进可复用的做法。
- **Embedding 检索**：用于查找相关记忆，可按界面选项使用内嵌本地模型或配置其他服务。
- **语音识别 ASR**：把语音转成文字。语音输入还需要麦克风权限。
- **生图模型**：用于生成图片。

暂时不用语音或生图，可以保留未配置，不影响文字任务。

## 模型不可用时

先检查「模型配置」里是否已保存连接，再确认「Agent 任务模型」已选中可用模型。自定义 API Key 连接失败时，核对协议、地址、模型 ID、Key、服务商额度和网络；修正后重新测试。

仍然失败时，记下错误提示和操作步骤，到「关于 → 高级 / 开发者」导出诊断报告，用于反馈问题。
