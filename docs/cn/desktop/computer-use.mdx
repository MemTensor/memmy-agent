## 设置应用权限

首次访问应用时，Memmy 可能显示「应用操控审批」，其中有三个选择：

<div className="docs-actions-table">

| 选择 | 生效范围 |
| --- | --- |
| **允许一次** | 只对当前这条消息有效。 |
| **始终允许** | 记住这个应用，之后使用它时不再逐次询问。 |
| **阻止** | 不允许本次访问。 |

</div>

系统权限单独按提示处理。例如 macOS 可能要求开启辅助功能；需要重启时，完成授权后重启 Memmy 再继续。

在工作台左下角打开「设置 → 电脑操控」，可以查看连接状态和「始终允许的应用」。顶部的「始终允许任意应用」用于省去逐应用询问，范围也包含内置浏览器和已连接的 Chrome、Edge。保持关闭时，按任务中的访问提示选择即可。

## 连接浏览器或 Excel

**Chrome / Edge**：在同页点击浏览器旁的「安装」，按展开指引添加 Memmy 扩展。确认出现「已连接，可操作此浏览器中的网页」后，再指定要处理的网页。

**Microsoft Excel**：打开要处理的工作簿，再开启同页的「Microsoft Excel」选项。按系统提示允许控制 Excel，回到 Memmy 确认状态为「已连接」。这项连接按应用授权，任务中仍应写明目标工作簿、工作表和要处理的范围。

## 执行时与完成后

保持目标应用打开、电脑处于可交互状态。任务需要补充信息或确认时，先处理提示；要改变要求，在原任务中说明。要中止当前执行，点击「停止」。

完成后回到原应用，检查目标内容是否符合要求；生成了文件时，打开实际文件核对。文本编辑器里的只读示例应只返回清单，原文件保持原样。写入 Excel 的示例只应改工作表「培训安排」的 A1:D6，未确定的内容保持为待确认。

## 撤销某个应用的持续授权

在「电脑操控 → 始终允许的应用」中，点击应用右侧的「×」，阅读提示后选择「移除」。下次使用这个应用时，Memmy 会重新询问。

如果开启了「始终允许任意应用」，先关闭它，再移除单个应用的持续授权，才能恢复按应用询问。

## 无法操作时

<details>
<summary>找不到应用或目标窗口</summary>

先打开应用和文件，保持电脑已解锁。在任务中补充应用名称、窗口标题或文件名，避免只说“帮我改这个”。

</details>

<details>
<summary>授权后仍然失败</summary>

核对系统权限是否生效，以及是否提示重启。浏览器检查扩展连接，Excel 检查「已连接」或具体错误说明；提示辅助程序缺失时，检查安装包并保留错误信息用于反馈。

</details>

<details>
<summary>电脑操控与电脑历史记录有什么区别？</summary>

电脑操控执行当前交给 Memmy 的任务；电脑历史记录回顾允许采集的应用和网页活动。它们分别设置，开启历史记录不等于授权操作应用。

</details>
