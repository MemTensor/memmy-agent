## 打开生成的文件

点击回复下方的**文件卡片**，或正文中的文件链接。支持预览的文件会在右栏打开；多个文件会形成多个标签，点击标签可以切换，点击「×」关闭预览。

下面用同一份清单的 Markdown 和 CSV 两种格式演示完整预览：

<ProductFileGuide markdownScreen={previewScreen} csvScreen={csvScreen} />

预览区域右上角有两个常用按钮：

- **用默认应用打开**：用电脑上的应用打开文件。
- **在文件夹中显示**：在系统文件管理器中定位文件，查看它保存在哪里。

全屏查看后，点击右上角「退出全屏」回到对话与右栏。

## 查看产物与原始材料

点击右栏左上角的列表图标「概览」。弹出的面板默认列出「产物」，可重新打开任务交付的文件。

要浏览项目中的原始材料，点击面板里的「概览」下拉菜单，切换到「工作空间文件」，再点击文件名。

<details>
<summary>文件打不开或没有预览</summary>

- 提示“文件已移动、删除或无法访问”时，确认文件仍在原位置，再点击「重试」。
- 提示格式不支持或文件较大时，选择「用默认应用打开」。
- 如果生成的文件仍打不开，把文件名和错误信息发在原任务里，让 Memmy 检查并重新生成。

</details>
