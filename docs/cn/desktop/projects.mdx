同一项工作需要多次对话、反复使用一批文件时，可以建一个项目。项目对应一个本地文件夹，相关任务会列在项目下面。

## 打开材料文件夹

1. 在左侧「项目」标题旁点击「添加项目」图标。
2. 在弹出的菜单中选择「打开本地文件夹」，再用系统窗口选中材料文件夹。
3. 回到 Memmy，确认输入框下方显示了这个项目的名称，再输入任务。

也可以在新任务页点击输入框下方的「选择项目」，选择已有项目或打开其他文件夹。

## 整理项目

把鼠标移到项目名称上，点击右侧的「…」打开「项目操作」菜单。

<div className="docs-actions-table">

| 操作 | 作用 |
| --- | --- |
| **置顶项目** | 把常用项目放到置顶区域。 |
| **在文件夹中显示** | 在系统文件管理器中定位本地文件夹。 |
| **全部标为已读** | 把这个项目里的任务标为已读。 |
| **归档任务** | 归档该项目的任务；运行中的任务不会停止。可从「任务列表操作 → 仅看归档」找回。 |
| **移除项目** | 移除项目并永久删除其中的任务。磁盘上的文件夹和文件保留。确认框会显示任务数量。 |

</div>

<details>
<summary>文件夹打不开或找不到材料</summary>

确认文件夹没有被移动或删除，外接磁盘仍已连接，再用「打开本地文件夹」重新选择。只处理一份材料时，也可以用输入框旁的「+」添加文件。

</details>
