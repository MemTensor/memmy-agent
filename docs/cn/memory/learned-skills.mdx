技能（Skill）保存一套可重复使用的做法。Memmy 会整理你本机已有的技能，也会从任务中总结可复用的技能，供后续工作参考。

## 查看步骤和来源

1. 打开「记忆管理 → 技能」。可以输入关键词并按 Enter 搜索。
2. 点击一条技能，查看「适用场景」和「SKILL.md 内容」，确认步骤适合这次任务。
3. 有「来源经验」或「证据锚点」时，点击其中的编号，查看对应记录。

## 在任务中复用

做后续工作时，Memmy 会想起用得上的技能，并按其中的做法来做。

「跨Agent接入」中安装的 `memmy-memory` Skill 负责让其他 AI 读写共享记忆；「技能」页管理的是具体工作方法。要连接其他 AI，在「记忆管理 → 跨Agent接入」找到对应工具，按它提供的安装入口操作。

## 修改电脑历史技能

来自电脑历史的技能可能已经自动启用，也可能仍待复核。先阅读详情顶部的提示；显示「修改」按钮时：

1. 点击「修改」，在「修改 Skill 内容」中调整步骤。
2. 点击「保存」，再检查正文里的改动。保存后会保留来源记录，并按修改后的内容参与召回。
3. 不想保存这次更改时，点击「返回」。

提示“来源已更新”时，重新核对保留的修订内容，再按页面提示保存。
