如果你同时使用 Cursor、Claude Code、Codex 等工具，可以把它们的历史对话带进 Memmy，再决定是否让它们持续使用和更新记忆。

## 导入已有对话

1. 打开「记忆管理 → 跨Agent接入」。
2. 在「已发现的 Agent」中找到对应工具。还没同步过时点击「首次扫描」，之后使用「同步新增」。
3. 等待摘要和索引处理完成，到「记忆管理 → 记忆」搜索一个熟悉的项目名。

首次扫描会整理一部分近期历史，之后只同步新增对话。扫描对话与安装记忆接入组件是两个独立按钮。

<details>
<summary>没找到工具，或需要更早的历史</summary>

内置来源包括 Cursor、Claude Code、Codex、OpenCode、OpenClaw、Hermes、DeepSeek Harness、WorkBuddy、Pi 和 qwenwork。列表只展示本机检测到的来源；先确认工具已使用过，并保存了本地历史。

在列表下方展开「高级」，点击「添加其他 Agent」。选择或输入框架名称，历史会话路径可以留空；确认后，Memmy 会新建任务，协助查找历史目录并完成接入。

需要补充更早的历史时，在「高级」中选择「扫描全部历史」。处理时间和模型消耗可能更多。

</details>

## 让其他 AI 使用记忆

在目标工具那一行，点击「安装 Hook」「安装插件」或「安装 Skill」。安装后，状态会变为「已安装 Hook」「已安装插件」或「已写入 Skill」，操作按钮也会变为「移除」。

## 调整自动同步

向下找到「自动同步」，分别控制：

- **启动时主动扫描**：Memmy 启动后扫描已接入 Agent 的新增会话。
- **定时扫描**：Memmy 运行期间每小时扫描一次新增会话。
- **发现新 Agent 时自动接入**：为新发现的工具安装接入组件；关闭后由你手动接入。

<details>
<summary>不同接入方式如何使用记忆？</summary>

- Claude Code、Codex、OpenCode、OpenClaw、Hermes 和 DeepSeek Harness 等接入，可在请求前查找相关记忆，并在回合结束后采集对话。
- Cursor 的 Hook 主要采集新对话和接续任务；记忆也可由 Skill 按需查找。
- WorkBuddy、Pi 和 qwenwork 使用 Skill 按需读写。

</details>

## 停止接入

在来源卡片上移除 Hook、插件或 Skill；需要停止历史同步时，也关闭自动同步。移除组件不会删除已经导入的记忆。

共享记忆不会搬运项目文件。要继续处理原来的文件，目标工具还需要能访问对应文件夹。
