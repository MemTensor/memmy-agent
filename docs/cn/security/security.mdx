Memmy 的记忆和配置默认保存在本机。接入其他 Agent 的历史时，Memmy 从本机可用的对话记录读取并整理内容。使用云端模型时，完成模型请求所需的内容会发送给所选模型服务；使用自定义 API Key 时，请同时查看对应服务商的数据政策。

## 记忆与历史在哪里？

配置、工作空间和记忆数据库默认位于本机的 `~/.memmy` 下。单条记忆可在详情底部删除；批量导出和清空入口在「记忆管理 → 跨Agent接入」页面底部的「数据管理」。

清除本地记忆会同时清空导入去重缓存和同步进度记录；模型配置、API Key 和账号信息不会因此一并删除。建议在清除前先导出需要保留的数据。

## 接入其他 Agent 时会改什么？

「首次扫描」整理近期历史，「同步新增」读取后续新增对话。扫描本身不会修改原 Agent 的配置；安装 Hook、插件或 Skill 时，会为对应 Agent 添加接入组件。移除这些组件不会自动删除已经导入的历史。

## 共享数据设置

在「设置 → 账户 → 隐私与改进计划」中，可以管理「共享数据」开关。界面会说明开启后收集的匿名行为数据；关闭后仍保留基础匿名启动统计。请以开关旁的当前说明为准。

## 电脑历史记录

电脑历史记录需要单独开启，并可设置应用和网站的采集范围。原始活动保存在本机，生成摘要时相关内容会交给所选模型处理。关闭开关会停止后续记录；删除已有历史时，对应的记忆与相关 Skill 也会一并删除。

## 知识库和外部服务

知识库文件会上传至服务端处理和检索。开启共享后，授权成员可以访问对应资料；删除文件也会影响共享使用方。

连接外部服务后，Memmy 的访问范围受连接授权和服务账号权限控制。可以在「连接与工具」中查看连接状态，并在不需要时断开。
