## 开始使用与模型

<details>
<summary>需要先安装命令行工具吗？</summary>

不需要。下载安装 Memmy，完成欢迎页设置后，就可以在工作台输入任务并发送。

</details>

<details>
<summary>一定要注册账号吗？</summary>

不一定。欢迎页提供「使用自定义大模型 API Key（无需注册）」。准备模型服务商提供的 API 地址、模型 ID 和 API Key，按照欢迎页步骤完成配置与连接测试即可。

</details>

<details>
<summary>没有配置语音或生图模型，能聊天吗？</summary>

可以。语音识别和生图是可选配置，不影响普通文字任务。需要时再到「设置 → 模型配置」添加对应模型，并在「模型分配」中选中它。

</details>

<details>
<summary>为什么无法发送，或提示当前模型不可用？</summary>

1. 打开「设置 → 模型配置」，确认模型库中已有可用连接。
2. 在下方「Agent 任务模型」中确认已选中可用模型，再回工作台检查「会话模型」。
3. 自定义连接需要核对协议、API 地址、模型 ID、API Key、服务商额度和网络，修正后重新测试。

如果仍然失败，记下错误提示；「设置 → 关于 → 高级 / 开发者」可以导出诊断报告。

</details>

## 记忆与资料

<details>
<summary>为什么同步了很多消息，新增记忆却更少？</summary>

Memmy 会按完整对话轮次整理消息，并去除重复或不完整内容。同步消息数和记忆条数不是一一对应的。

</details>

<details>
<summary>为什么刚同步的对话还搜不到？</summary>

在「记忆管理 → 跨Agent接入」查看对应来源的扫描状态，等待同步、摘要和索引完成。再到「记忆」中用原对话里的具体词语搜索。

如果来源显示失败，先按错误提示检查历史文件位置和模型配置，再重试同步。

</details>

<details>
<summary>退出登录会删除记忆吗？</summary>

不会。退出登录会清除账号登录状态，本机已有对话和记忆保留。

删除记忆是单独的操作：单条删除在记忆详情中，批量清空在「记忆管理 → 跨Agent接入」底部的「数据管理」。批量清空前先导出需要保留的数据。

</details>

<details>
<summary>记忆保存在什么地方？</summary>

配置、工作空间和记忆数据库默认位于本机的 `~/.memmy` 下。导出入口在「记忆管理 → 跨Agent接入」底部的「数据管理」。

使用云端模型时，处理所需内容会发送给所选模型服务；知识库文件会上传至服务端处理和检索。

</details>

<details>
<summary>知识库里有资料，回答却没有用到？</summary>

打开目标知识库，确认文件状态为「可用」，并开启右上角的「参与召回」。提问时写明知识库名称、文件名和要找的内容，再检查回答引用的资料。

如果文件仍显示「处理中」，等待处理完成；显示「失败」时，查看文件名下方的错误说明，修正后重新上传。

</details>

<details>
<summary>换一个 Agent 后没有接上之前的任务？</summary>

先在 Memmy 的「记忆」中搜索原任务，确认内容已经整理进来。再到「跨Agent接入」检查目标 Agent 的接入状态，按对应方式确认 Hook、插件或 Skill 可用。

在新对话中说明原任务主题和要继续的工作。共享记忆不会自动传输工作文件，目标 Agent 也需要能访问所需材料。

</details>

## 文件与任务

<details>
<summary>项目中的文件为什么找不到？</summary>

检查输入框下方绑定的项目是否正确，以及项目文件夹是否被移动、删除或所在磁盘已断开。需要重新选择时，使用「添加项目 → 打开本地文件夹」；也可以通过输入框的附件入口直接添加材料。

</details>

<details>
<summary>生成了结果，文件在哪里？</summary>

点击回复中的文件卡片，会在右栏打开预览。也可以打开右栏「概览」查看产物；查找原始材料时，在面板下拉菜单切换到「工作空间文件」。

预览顶部的「在文件夹中显示」可以定位本机文件。若回复没有文件卡片或路径，可要求 Memmy 确认是否已生成文件及实际保存位置。

</details>
