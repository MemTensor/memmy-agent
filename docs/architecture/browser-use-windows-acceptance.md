# Memmy Browser Use：Windows x64 验收

此表用于本地自动检查完成后的 Windows 实机人测。测试包应由当前工作区生成；不要用旧安装包判断本轮改动。

## 准备

1. 在 Windows x64 测试机安装本轮 Memmy 测试包，启动并完成 Agent 登录。首次启动需等待浏览器组件准备完成。
2. 建立一个测试任务，准备可访问的普通 HTTPS 页面和一个本机开发 URL（例如 `http://localhost:3000`）。
3. 记录 Memmy 版本、Windows 版本、显示器数量和缩放比例；若失败，保留桌面日志与 `browser-prepare.log`。

## 浏览器与 Computer Use 联动

| 步骤 | 应看到的结果 |
| --- | --- |
| 从任务右侧栏打开“浏览器”，输入 HTTPS 地址 | 页面画面显示在右栏；地址、前进、后退和刷新可用。 |
| 让 Agent 在同一任务使用 `browser_navigate`、点击和输入 | 右栏显示 Agent 正在操作的同一页面；登录状态和导航不分叉。 |
| 在右栏点击、滚动和输入，再让 Agent 读取页面 | Agent 看到用户刚才操作后的页面。 |
| 关闭右栏，继续让 Agent 浏览，再打开“浏览器” | 当前页面和访问历史仍在。 |
| 点击“打开同一标签页” | 原生浏览器窗口可见，页面与右栏一致。 |
| Agent 在后台浏览时切换到其他应用 | Memmy 不应抢前台焦点；右栏／浮窗仍应显示有效画面。 |
| 关闭任务浮窗后再次打开右栏 | 关闭浮窗不应结束底层浏览器会话。 |

## 数据与稳定性

| 步骤 | 应看到的结果 |
| --- | --- |
| 登录测试站点，退出并重启 Memmy | Cookie 和网站本地存储恢复，Agent 与右栏使用相同登录状态。 |
| 搜索浏览历史并删除一条记录 | 删除后重启仍不出现该记录。 |
| 在测试站点下载文件，从右栏“下载记录”定位 | 文件出现在文件管理器中；重启后下载记录仍在。 |
| 在右栏更改下载位置后重新下载 | 新文件进入所选目录；旧记录仍能定位；恢复默认后新文件进入 Memmy 数据目录。 |
| 启用“每次下载前询问保存位置”并下载 | 系统保存对话框出现；选择的文件名和位置准确生效，取消则不添加下载记录。 |
| 让 Agent 打开未访问过的网站 | 弹出访问审批；仅本次允许可访问，阻止会中止导航，始终允许在重启后保留。 |
| 浏览器批注 | 已从 Memmy 右栏移除，不纳入当前浏览器验收。 |
| 保存一个测试站点的测试密码与联系人，再点击填充 | 当前站点输入框被填入；换到另一个网站时无法填入该站点密码；重启后条目仍在。 |
| 在测试站点授予摄像头权限，再取消授权 | 修改后当前网页刷新；重启后授权状态保留，取消后不再授权。 |
| 使用“清除浏览数据” | 当前页面会话关闭；重启后网站登录状态和浏览历史已清除。 |
| 清除浏览数据后检查此前下载的文件 | 下载记录已清空，文件仍保留。 |
| 清除浏览数据后检查网站权限 | 此前按网站保存的授权已清空。 |
| 输入本机开发 URL | 使用 HTTP 打开本机服务，不错误改成 HTTPS。 |
| 浏览器不可用或页面长期无响应 | 右栏显示可理解的错误，不无限停留在“正在打开”。 |
| 在 100% 和 150% 缩放、多显示器下重复点击与滚动 | 点击位置与画面目标一致，窗口显隐和焦点行为正常。 |
