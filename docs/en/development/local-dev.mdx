## One-Command Start

Get running in three steps:

```bash
git clone https://github.com/MemTensor/memmy-agent.git && cd memmy-agent
cp .env.example .env         # Cloud address is pre-filled — works out of the box
bash scripts/dev-start.sh    # Install deps → build → start the full stack
```

`scripts/dev-start.sh` installs dependencies, builds memmy-agent and the Memory CLI, and links `memmy` / `memmy-memory` into `~/.local/bin`. It starts the Agent API, the frontend, and Electron directly. Electron manages Memory and the Gateway. The Agent API waits until the account or BYOK model config has been written, then starts.

> `MEMMY_CLOUD_SERVICE` in `.env` defaults to `https://api.memmy.cn`. Use the origin only; clients append `/api/...` paths. Copying it connects you to the official cloud, with no self-hosted backend or API key required. On Windows, run the script in Git Bash; it adds `~/.local/bin` to `PATH`.

## Requirements

Local development uses Node.js 22 or newer, plus npm. `App/memmy-agent` declares `engines` of `>=22`. The root `package.json` `engines` field still says `>=20`; use 22 for local development.

The Linux CLI installer is stricter. It accepts only Node.js 22.23.4 or newer within 22.x, 24.22.1 or newer within 24.x, or 26.12.1 or newer within 26.x. Other major versions are rejected. That check lives in `scripts/install.sh` and does not change the local development requirement above.

Root workspaces include `Migrations`, `AgentSourceCore`, `Knowledge`, `Memory`, `App/backend/local-api-contracts`, `App/backend`, `App/frontend/*`, `App/shell/desktop/interface`, and `App/shell/*`.

## Common Commands

```bash
npm install            # Install dependencies at the repo root
npm run dev:desktop    # Start the desktop frontend Vite server and Electron shell together
npm run build          # Build Memory and all workspaces
npm run lint
npm run typecheck
npm run test
npm run db:migrate     # Run backend database migrations
npm run package:mac    # Package the macOS DMG
npm run package:win:x64
```

## Developing Memory Standalone

```bash
npm run memory:serve:dev -- \
  --host 127.0.0.1 \
  --port 18960 \
  --db ~/.memmy/memory-service/memory.sqlite \
  --config ~/.memmy/config.yaml
```

## memmy-agent from Source

```bash
cd App/memmy-agent
npm install && npm run build
node dist/main.js onboard
node dist/main.js agent --message "Hi, introduce the current workspace"
node dist/main.js serve
```
