Put handbooks, course material, or project notes in a knowledge base when you need to look them up across many tasks. A knowledge base requires a Memmy account. Files are uploaded for processing and search.

## Create a base and add files

1. In the workbench sidebar, open **Knowledge**, then choose **+** beside the knowledge base list (**New knowledge base**).
2. Enter a name, such as “Customer support handbook”, and choose **Create**.
3. Open the new base, choose **Upload files → Local files**, and select the material. To add a whole folder at once, choose **Folder**. You can also drag files into the file area.

You can download this <a href="/docs-examples/support-handbook-en.md" download>sample customer support handbook</a> to practice.

PDF, Word, TXT, Markdown, JSON, and XML are supported, up to 100 MB each. After upload, read the file status:

<div className="docs-actions-table">

| Status | What to do next |
| --- | --- |
| **Processing** | Wait for parsing and indexing. The list updates the status. |
| **Available** | The file is ready. You can turn on **Recall**. |
| **Failed** | Read the error under the file name, fix the file or format, and upload it again. |

</div>

## Turn on Recall

Turn on **Recall** at the top right of the knowledge base so related chats can search it. Turning it off keeps the files in the base. You can turn it on later.

## Organize the files

When there are many files, use **Search files** at the top, or **New folder** to group them. Right-click a file and choose **Move to…**.

To update material, upload the new version, wait until it is **Available**, then remove the old one. Delete on the right of a file row asks you to confirm first. It deletes the cloud file in the knowledge base and affects other people using that base.

<details>
<summary>Delete a whole knowledge base</summary>

Open **…** (**More**) at the top of the knowledge base and choose **Delete knowledge base**. The confirmation says the base and all of its files will be permanently deleted and cannot be restored.

</details>

## Share with someone else

1. Open a knowledge base you own and choose **Sharing**.
2. Enter the other person’s Memmy user ID, phone number, or email, then choose **Add**. They can copy the user ID from **Account**.
3. They open it under **Shared** in the knowledge list and turn on **Recall** themselves.

A shared base is marked **Shared** and says **View and recall only**. To stop sharing, choose **Remove** in **Sharing**, then confirm **Unshare**.
