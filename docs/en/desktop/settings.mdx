## Choose a model source

After you sign in to a Memmy account, you can use the platform models available on that account, or add your own API key. If you do not want to sign up, choose **Use a custom LLM API Key (no sign-up needed)** on the first welcome screen. Account mode and local API key mode manage model configuration separately.

## Use your own API key

1. Open **Settings → Model configuration** and choose **Add configuration** at the top right.
2. Enter the **Protocol type**, **API URL**, and **API Key** from the model provider.
3. Under **Model list**, enter the **Model ID** and choose **Model capability**. For ordinary chat, choose **General text**. If the same service has more than one model, choose **Add model**.
4. Choose **Test** and fix the connection from the message you get. After the test passes, choose **Save**. The configuration appears in the model library.

## Use this model for tasks

After you save the configuration, open **Model assignments → Agent task models** lower on the same page. Choose the button that shows how many are selected, check the models that can be used, and set the default. Back on the workbench, choose the model for this task under **Conversation model**.

<details>
<summary>What are the other model assignments for?</summary>

- **Memory summary**: turn a conversation into memory.
- **Skill evolution**: organize and improve methods that can be reused.
- **Embedding search**: find related memory. Use the built-in local model, or configure another service, from the options on the page.
- **Speech recognition ASR**: turn speech into text. Voice input also needs microphone permission.
- **Image generation model**: create images.

If you are not using speech or image generation yet, leave them unset. Text tasks still work.

</details>

## When a model is unavailable

First check that a connection is saved under **Model configuration**, then confirm **Agent task models** has a usable model selected. If a custom API key fails to connect, check the protocol, URL, model ID, key, provider quota, and network. Test again after you correct them.

If it still fails, write down the error and the steps you took. Export a diagnostic report from **About → Advanced / developer** and include it with the feedback.
