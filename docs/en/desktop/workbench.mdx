## Use voice, or change the model

**Voice input** turns speech into text. The first time, it needs microphone permission and a working speech-recognition model. For a longer discussion, open **Recording** on the workbench and record or upload audio.

**Conversation model** switches the model for the current task. If the model is unavailable, open **Settings → Model configuration** and check the configuration and quota.

## Find an existing task

The task list on the left can search, rename, pin, and archive. Archive a task you may continue later but do not need right now. Before you delete one, confirm you no longer need it.

Type `/` in the input to see the commands that are available. For an ordinary task, plain language is enough.
