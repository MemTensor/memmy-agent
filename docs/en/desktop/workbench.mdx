`/main` is the full Agent workbench: task list on the left, message stream in the middle, input box at the bottom.

## Input & Sending

- `Enter` to send, `Shift + Enter` for a new line; IME composition (e.g. Chinese input) is handled correctly.
- The `+` button adds attachments: up to 4, 10MB each, supporting images and common formats like `.pdf`, `.docx`, `.xlsx`, `.pptx`, `.md`, `.csv`, `.json`.
- The microphone button enables voice input (requires an ASR model); transcriptions merge into the input box.
- While a task is running, the send button becomes a stop button.

## Slash Commands

Type `/` to open the command panel:

| Command | Purpose |
| --- | --- |
| `/new` | Start a new task |
| `/stop` | Stop the current task |
| `/restart` | Re-run the current task |
| `/status` | Check the Agent's runtime status |
| `/model` | View the current model configuration |
| `/goal` | View or manage goal state |
| `/dream` | Manually trigger memory consolidation |
| `/dream-log` | View consolidation records |
| `/dream-restore` | Restore the pre-consolidation state |
| `/help` | Help |

## Task List

Grouped by Pinned, Today, Yesterday, Last 7 Days, Older, and Archived. Supports rename, pin, archive, restore, and delete; running tasks show a spinner, and completed-but-unread tasks show an unread dot. `Cmd/Ctrl + K` opens task search.


## Project Context Pack

When the current chat belongs to a registered project, the composer toolbar shows **Context Pack**. The dialog displays a Markdown pack generated from active project memories, including conventions, common commands, architecture facts, recent tasks, and user preferences. Individual entries open their complete memory detail and evidence graph.

The **Project governance** section shows the confirmed goal and focused work item. You can approve or reject candidate goals and select or clear the current focus. Candidate goals do not affect Agent prompts until approved.

This state is scoped to the project rather than to one Agent. Installed CLI integrations that resolve the same workspace receive the confirmed goal, constraints, and focus automatically at the start of their next turn.
