## Use voice, or change the model

**Voice input** turns speech into text. The first time, it needs microphone permission and a working speech-recognition model. For a longer discussion, open **Recording** on the left and record or upload audio.

**Conversation model** switches the model for the current task. If the model is unavailable, open **Settings → Model configuration** and check the configuration and quota.

## Find an existing task

The task list on the left can search, rename, pin, and archive. Archive a task you may continue later but do not need right now. Before you delete one, confirm you no longer need it.

Type `/` in the input to see the commands that are available. A command you choose is inserted into the draft. Check it, then send. For an ordinary task, plain language is enough.

## Answer a follow-up question

When a task needs a choice, the chat shows **Your input is needed**. The card says **Choose one** or **Select all that apply**. Choose **Submit answer** when you are ready. If there are several questions, use **Previous question** and **Next question**, then **Confirm and continue**. You can **Skip**, or **Close without answering**. After you submit, the card shows **Answered**.

## Read the task plan

A running task may show **Task plan** and a count of completed items over the total. The status can be **Active**, **Waiting to continue**, **Completed**, or **Blocked**. When the turn stops, a plan that was active shows **Waiting to continue**. Choose the title to expand the items. The plan is a list of intended steps. It does not mean those steps are already done.
