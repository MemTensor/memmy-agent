Give Memmy a meeting or a lesson recording. Read the transcript first, then turn it into material you can keep working on. Recording requires a Memmy account.

## Open recording

1. In the left sidebar, choose **Recording** to open the recording list. **Start** on the same row begins recording immediately.
2. The list shows saved recordings. You can also **Upload recording** or **Start recording**.

## Record the discussion and read the transcript

The first time you record, allow the microphone when the system asks. While recording, you can **Pause** and **Continue**. When the discussion ends, choose **Stop and transcribe**. An uploaded audio file goes through transcription too.

When it finishes, choose the title in the recording list. Check speakers, names, numbers, and key decisions. If the original audio is there, play it back. Live text can be incomplete. Use the result after transcription finishes.

## Use the transcript in a task

| Choose | What happens |
| --- | --- |
| **Add to conversation** | The transcript is placed in the current task’s input as a TXT attachment. Add your request, then send. |
| **Summarise** | A new task is created with a summary request and the transcript attached. You can change the request, then send. |

<ProductScreenshot src={attachedScreen} alt="Full Memmy window with a transcript attached to the current task input" caption="After Add to conversation, confirm the transcript attachment is in the input, then say what you want." />

<details>
<summary>Transcription failed</summary>

If it says **Transcription failed; recording kept**, choose **Retry transcription** beside that recording. If speech transcription is unavailable, check that you are signed in, that the network works, and that a speech-recognition model is configured, then try again.

</details>
