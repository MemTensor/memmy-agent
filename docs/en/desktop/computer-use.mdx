When a task has to be done in a desktop app, Memmy can look at the current window and carry out the actions. Confirm app permission first, then open the app and the file and say what to do and what the result should be.

## Set app permission

The first time Memmy needs an app, it may show **App control approval**, with three choices:

<div className="docs-actions-table">

| Choice | What it covers |
| --- | --- |
| **Allow once** | Only the current message. |
| **Always allow** | Remember this app and do not ask every time it is used. |
| **Block** | Do not allow this access. |

</div>

System permissions are handled separately when they appear. macOS may ask you to turn on Accessibility. If a restart is required, grant access and reopen Memmy before you continue.

Open **Settings → Computer use** from the lower left of the workbench to see connection status and **Always allowed apps**. **Always allow any app** at the top skips the per-app question. It also covers the built-in browser and connected Chrome and Edge. Leave it off if you want to answer the prompt in each task.

## Connect a browser or Excel

**Chrome / Edge**: on the same page, choose **Install** beside the browser and follow the expanded steps to add the Memmy extension. After you see **Connected. Memmy can use web pages in this browser.**, name the page to work on.

**Microsoft Excel**: open the workbook you want to use, then turn on **Microsoft Excel** on the same page. Allow control of Excel when the system asks, then return to Memmy and confirm the status is **Connected**. This connection is granted for the app. In the task, still name the workbook, the sheet, and the range to change.

## While it runs, and after it finishes

Keep the target app open and the computer unlocked. If the task asks for more information or a confirmation, answer that first. To change the request, say so in the original task. To stop the current run, choose **Stop**.

When it finishes, go back to the original app and check that the result matches the request. If a file was created, open that file. The read-only text-editor example should only return a list, and the original file should stay unchanged. The Excel example should change only A1:D6 on the Training plan sheet, and anything still undecided should stay to be confirmed.

## Remove ongoing permission for one app

Under **Computer use → Always allowed apps**, choose **×** on the right of the app, read the prompt, and choose **Remove**. The next time that app is used, Memmy asks again.

If **Always allow any app** is on, turn it off before you remove one app’s ongoing permission. Otherwise Memmy will not return to asking per app.

## When it cannot operate

<details>
<summary>The app or window cannot be found</summary>

Open the app and the file, and keep the computer unlocked. In the task, add the app name, window title, or file name. Do not only say “change this”.

</details>

<details>
<summary>It still fails after you allow it</summary>

Check that the system permission is in effect, and whether Memmy asked you to restart. For a browser, check the extension connection. For Excel, check **Connected** or the specific error. If it says the helper is missing, check the installer and keep the error text for feedback.

</details>

<details>
<summary>How is computer use different from Computer History?</summary>

Computer use carries out the task you give Memmy now. Computer History reviews activity from the apps and websites you allowed it to record. They are set up separately. Turning on history does not allow Memmy to operate apps.

</details>
