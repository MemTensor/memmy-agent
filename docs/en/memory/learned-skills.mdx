A skill saves a method you can repeat. Memmy organizes skills already on this machine, and also summarizes reusable skills from tasks for later work.

## Read the steps and the source

1. Open **Memory → Skills**. Type a keyword and press Enter to search.
2. Open a skill and read **When to use** and **SKILL.md content**. Confirm the steps fit this task.
3. If **Source experiences** or **Evidence anchors** are present, choose a number to open the matching record.

## Reuse it in a task

On later work, Memmy recalls a skill that fits and follows that method.

The `memmy-memory` Skill installed from **Cross-Agent access** lets another AI read and write shared memory. **Skills** is where specific work methods are managed. To connect another AI, open **Memory → Cross-Agent access**, find the tool, and use the install action it offers.

## Edit a Computer History skill

A skill from Computer History may already be enabled, or it may still need review. Read the notice at the top of the details. When **Edit** is shown:

1. Choose **Edit** and change the steps in **Edit Skill content**.
2. Choose **Save**, then check the change in the body. Saving keeps the source records and uses the edited content for recall.
3. Choose **Back** if you do not want to save this change.

If it says the sources changed and your edited content was kept, review that content again, then save it as the page asks.
