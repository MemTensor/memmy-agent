Computer History turns your activity in apps and websites into summaries. Later tasks can pick up where you left off, find a file you just opened, or turn a flow you just finished into a skill.

It records only after you turn it on. You choose which apps and websites contribute, and you can review, pause, or delete the history at any time. It is available on macOS and Windows 11.

## Start recording

1. Open **Memory → Computer History**. The first time, choose **Set up History**. If records already exist, turn on **Enable computer activity recording** on the right.
2. Read the explanation, choose **Enable recording**, choose which apps and websites to include, then choose **Continue and enable**.
3. On macOS, if Accessibility is not enabled, choose **Enable** and finish the system permission. If you see **Quit & Reopen**, follow it so the permission takes effect.
4. Return to the page and confirm it says **Recording**.

## Find the work you just did

After you have used the computer for a while, scroll to the history. Read the summaries by date. Move the pointer over an item and choose the document icon beside the title to open the full record.

From the workbench, you can say:

- What was I working on before my last break?
- What was that planning file I looked at today?
- I just finished the video upload flow. Let's use this next time.

Once the right material is found, you can ask for a to-do list or a draft of the next step. If the summary is incomplete, add the original file or URL.

## Change what is recorded

On the **Permissions** row, choose **Choose** or the button that shows how many items are selected, such as **3 selected**, and adjust the app and website rules. **Include only these apps** or **Include only these websites** records only the list. **Exclude these apps** or **Exclude these websites** skips the list. New activity follows the saved rules.

Pictures, sound, and content that cannot be read are not recorded in full. Native recording can include a foreground browser’s private window. Add websites you want to skip to the exclude list.

**Enhanced webpage history** uses the browser extension to add web controls and action changes. It shares that extension with computer use, and it follows the Computer History recording settings.

**Allow reading WeChat chats** is a separate switch. Allowing ordinary Computer History does not allow Memmy to read WeChat chat data directly. Read that option’s full explanation first.

## Pause or delete

Turning the recording switch off stops collection. Existing records stay.

- **Delete one item**: hover the item, choose the trash icon beside the title, and confirm. Stop a segment that is still being recorded before you delete it.
- **Clear today or everything**: choose **Clear history**, pick **Clear today** or **Clear everything**, and confirm.

Clearing history also deletes the matching memories and related skills. It cannot be undone. If it says deletion is still in progress, wait. A failure is retried automatically.

## No new summary?

Check that the status is **Recording**, that the system permission is in effect, and that the app is inside the recording scope. If there was activity but the summary is still being organized, check again later. If the model is unavailable or the quota is used up, open **Settings → Model configuration**.

## Where is it stored?

Raw records stay on this computer. When a summary is created, the needed content is sent to the model you configured. An online model receives that content. A platform model is processed by the Memmy service.
