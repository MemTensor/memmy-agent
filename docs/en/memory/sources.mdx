If you use tools such as Cursor, Claude Code, and Codex, you can bring their chat history into Memmy, then decide whether they keep using and updating that memory.

## Import existing chats

1. Open **Memory → Cross-Agent access**.
2. Find the tool under **Detected Agents**. If it has not synced, choose **First scan**. After that, use **Sync new**.
3. Wait until summaries and indexing finish, then open **Memory → Memories** and search for a project name you recognize.

The first scan organizes some recent history. Later scans only sync new conversations. Scanning chats and installing the memory connector are two separate buttons.

<details>
<summary>The tool is missing, or you need older history</summary>

Built-in sources include Cursor, Claude Code, Codex, OpenCode, OpenClaw, Hermes, DeepSeek Harness, WorkBuddy, Pi, and qwenwork. The list only shows sources detected on this computer. Confirm that the tool has been used and that it saved local history.

At the bottom of the list, expand **Advanced** and choose **Add another Agent**. Choose or type the framework name. The history path can stay empty. After you confirm, Memmy creates a task that helps find the history folder and finish the connection.

<ProductScreenshot src={manualScreen} alt="Memmy dialog for adding another Agent name and an optional history path" caption="The name is required. Add a path if you know where the history is stored, or leave it empty." />

To add older history, choose **Scan all history** under **Advanced**. It can take longer and use more of the model.

</details>

## Let other AIs use memory

On the tool’s row, choose **Install Hook**, **Install plugin**, or **Install Skill**. After installation, the status becomes **Hook installed**, **Plugin installed**, or **Skill installed**, and the button changes to **Remove**.

Once the background is right, continue with the next step. If the tool says it is not connected, check the install status on the source card and reopen the session as that tool asks.

## Change automatic sync

Scroll to **Auto sync**. Each switch is separate:

- **Scan on startup**: after Memmy starts, scan connected Agents for new sessions.
- **Scheduled scan**: while Memmy is running, scan for new sessions once an hour.
- **Auto-connect newly found Agents**: install the connector for a newly detected tool. Turn this off if you want to connect tools yourself.

<ProductScreenshot src={preferencesScreen} alt="Memmy Cross-Agent access showing the three automatic sync switches" caption="The three switches control startup scans, scheduled scans, and connecting new Agents. Change them separately." />

<details>
<summary>How does each connection use memory?</summary>

- Connections such as Claude Code, Codex, OpenCode, OpenClaw, Hermes, and DeepSeek Harness can look up related memory before a request and collect the conversation after the turn.
- The Cursor Hook mainly collects new chats and follow-up tasks. Memory can also be looked up on demand through the Skill.
- WorkBuddy, Pi, and qwenwork read and write memory on demand through the Skill.

</details>

## Stop a connection

Remove the Hook, plugin, or Skill on the source card. To stop history sync as well, turn off automatic sync. Removing the connector does not delete memory that was already imported.

Shared memory does not move project files. To keep working on the original files, the other tool also needs access to that folder.

<details>
<summary>Codex Hook installation fails</summary>

Seeing Codex in the list means its session directory was found. Hook installation also requires a runnable Codex CLI. Memmy checks the plugin directory, PATH, macOS application bundles, the Windows desktop runtime cache, and common npm locations. For a custom installation, set `MEMMY_CODEX_EXECUTABLE` to the absolute CLI path and restart Memmy. `CODEX_CLI_PATH` is also supported, with the Memmy-specific setting taking precedence. Select the CLI, not the desktop application's launcher. An unavailable path fails installation before new Hook files are written.

</details>
