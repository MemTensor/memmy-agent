In the workbench sidebar, open **Connections & Tools** and choose **Task plugins** at the top.

These plugins are provided and maintained by Memmy. Installing one adds a complete capability to the current task. The cards and their details show which plugins are in the catalog and what each one does. When a plugin needs sign-in, is not open yet, or you do not have access, the card says so.

App tools connect an external account. Chat channels send Memmy a task from a messaging app.

## Install and add to chat

1. Browse the current catalog under **All**, or type a name in **Search task plugins**.
2. Choose **+** on the right of the card. A plugin that needs an account shows **Sign in**.
3. After installation, the card shows that it is installed. Choose the chat icon, whose tooltip is **Try it**. You can also open **View details** and choose **Add to chat**.

After it is in the chat, say what you want done from the workbench. **Installed** in the filter shows only plugins already installed.

## Uninstall

On an installed plugin, open **…** and choose **Uninstall**. After you confirm, new tasks cannot use that plugin. Tasks and files already finished stay. You can install it again later.

<details>
<summary>The catalog will not open, or installation did not finish</summary>

- If it says the remote plugin catalog is unavailable, installed plugins can still be used. Choose **Refresh** and try again.
- If installation did not finish, choose **Retry installation**.
- **Coming soon** or **Access unavailable** means you cannot install or use it yet.
- Installed, updating, and unfinished states are whatever the card shows. If a task is still running, let it finish before updating a plugin manually.

</details>
