## Getting started and models

<details>
<summary>Do I need to install a command-line tool first?</summary>

No. Download and install Memmy, finish the welcome screen, then type a task on the workbench and send it.

</details>

<details>
<summary>Do I have to create an account?</summary>

No. The welcome screen includes **Use a custom LLM API Key (no sign-up needed)**. Have the API URL, model ID, and API key from a model provider, then follow the welcome screen through configuration and the connection test.

</details>

<details>
<summary>Can I chat if speech or image generation is not configured?</summary>

Yes. Speech recognition and image generation are optional. They do not affect ordinary text tasks. When you need them, add the model under **Settings → Model configuration** and select it under **Model assignments**.

</details>

<details>
<summary>Why can I not send, or why does it say the current model is unavailable?</summary>

1. Open **Settings → Model configuration** and confirm the model library has a usable connection.
2. Under **Agent task models**, confirm a usable model is selected, then check **Conversation model** on the workbench.
3. For a custom connection, check the protocol, API URL, model ID, API key, provider quota, and network. Test again after you correct them.

If it still fails, write down the error. **Settings → About → Advanced / developer** can export a diagnostic report.

</details>

## Memory and material

<details>
<summary>Why are there fewer new memories than synced messages?</summary>

Memmy organizes messages by complete conversation turns, and it removes duplicates and incomplete content. The number of synced messages and the number of memories are not one to one.

</details>

<details>
<summary>Why can I not search a chat that just synced?</summary>

In **Memory → Cross-Agent access**, check that source’s scan status and wait until sync, summary, and indexing finish. Then search **Memories** for a specific phrase from the original chat.

If the source shows a failure, follow the error to check the history file location and the model configuration, then sync again.

</details>

<details>
<summary>Does signing out delete memory?</summary>

No. Signing out clears the account sign-in. Chats and memory already on this computer stay.

Deleting memory is a separate action. Delete one item from its details. Clear many from **Data management** at the bottom of **Memory → Cross-Agent access**. Export anything you want to keep before a bulk clear.

</details>

<details>
<summary>Where is memory stored?</summary>

Configuration, the workspace, and the memory database are under `~/.memmy` on this computer by default. Export is under **Data management** at the bottom of **Memory → Cross-Agent access**.

When you use a cloud model, the content needed for that request is sent to the model service you chose. Knowledge base files are uploaded for processing and search.

</details>

<details>
<summary>The knowledge base has files, but the answer did not use them</summary>

Open the knowledge base, confirm the file status is **Available**, and turn on **Recall** at the top right. In the question, name the knowledge base, the file, and what you want found, then check which material the answer cites.

If the file still says **Processing**, wait. If it says **Failed**, read the error under the file name, fix it, and upload again.

</details>

<details>
<summary>Another Agent did not pick up the earlier task</summary>

In Memmy, search **Memories** for the original task and confirm the content has been organized. In **Cross-Agent access**, check that Agent’s connection and confirm the Hook, plugin, or Skill for that method is available.

In the new chat, name the original topic and the work to continue. Shared memory does not transfer the working files. The other Agent also needs access to the material.

</details>

## Files and tasks

<details>
<summary>Why can a file in the project not be found?</summary>

Check that the project shown under the input is the right one, and that the project folder was not moved or deleted and its disk is still connected. To choose it again, use **Add project → Open local folder**. You can also add the material from the attachment button beside the input.

</details>

<details>
<summary>A result was generated. Where is the file?</summary>

Choose the file card in the reply. It opens in the side panel. You can also open **Overview** in the side panel to see artifacts. To find the original material, switch the panel menu to **Workspace files**.

**Show in folder** at the top of the preview reveals the file on this computer. If the reply has no file card or path, ask Memmy whether a file was created and where it was saved.

</details>
