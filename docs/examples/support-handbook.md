# 客户支持手册（练习材料）

这是一份虚构材料，仅用于体验知识库，不代表任何公司的实际制度。

## 收到问题后先确认

- 客户正在尝试完成什么目标。
- 问题出现在哪个步骤，能否重复出现。
- 使用的产品版本、操作系统和具体错误提示。
- 如需截图，请客户先遮盖账号、联系方式和其他敏感信息。

## 整理处理记录

每条记录包含：问题描述、复现步骤、已经尝试的办法、当前状态和下一步。
客户原话与支持人员的推测分开记录，尚未验证的原因标为“待验证”。

## 回复客户

先复述已经确认的问题，再给出下一步建议。暂时不能解决时，说明仍缺少哪些信息。
如果提供临时解决办法，应写明适用条件。

## 本材料没有规定的内容

服务时间、响应时限、退款条件和升级处理的负责人均未规定。回答这些问题时，应说明需要进一步确认。
